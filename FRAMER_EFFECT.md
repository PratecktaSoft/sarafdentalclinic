# Framer 50-Frame Effect

The 50 PNG animation frames live ONLY in `assets/images/` alongside the existing site images. There is intentionally no duplicate `assets/images/frames/` directory.

Files: `ezgif-frame-001.png` through `ezgif-frame-050.png`.

The homepage `index.html` uses `js/frame-sequence.js`, which loads these exact paths.
