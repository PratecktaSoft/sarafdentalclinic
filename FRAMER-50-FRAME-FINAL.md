# Framer 50-frame final behavior

The `.frame-sequence` section is a single pinned cinematic scene.
It remains visually full-screen while the user scrolls through all 50 PNG frames.
The next homepage section begins only after frame 50 / 100% progress.

Frames are loaded only from:
assets/images/ezgif-frame-001.png ... ezgif-frame-050.png

There is no separate `assets/frames` folder.
